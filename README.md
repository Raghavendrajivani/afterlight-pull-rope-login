# Afterlight Pull Rope Login

A stylish login page where you pull a rope to turn on the lamp and reveal the login form.

## Features

- Interactive pull rope for mouse and touch
- Show or hide the password
- Required-field validation
- Responsive design for desktop and mobile
- Separate HTML, CSS, and JavaScript files

## Run the project

Download or clone this repository, then open `index.html` in your browser.

## Files

- `index.html` — page structure
- `style.css` — styles and animations
- `script.js` — rope and login interactions

## Note

This is a front-end demo. Login does not connect to an authentication service.
